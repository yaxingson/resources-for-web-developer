#### 图形和组件

- [sinwaver](https://www.sinwaver.com/)：为你的设计和背景生成完美的正弦波并导出为SVG格式
- [heropatterns](https://heropatterns.com/)：一组免费且可重复使用的SVG背景图案，供您在数字项目中使用
- [transparenttextures](https://www.transparenttextures.com/)：一组透明纹理背景图案
- [patternico](https://patternico.com/)：在线快速轻松创建您自己的免费无缝图案和背景。试试我们的图案生成器——完全免费！
- [fffuel](https://www.fffuel.co/)：一个有趣的免费SVG生成器合集，可用于制作渐变、图案、形状、纹理及炫酷背景。此外，还包含一些面向网页设计师的实用色彩工具

#### 字体

- [dafont](https://www.dafont.com/)：免费字体下载存档。按字母顺序、样式、作者或人气浏览
- [fontsquirrel](https://www.fontsquirrel.com/)：Font Squirrel在互联网上搜罗高质量、完全合法的免费字体。您可以下载成千上万种完全合法且高质量的免费字体
- [practice.typekit](https://practice.typekit.com/)：无论你是某个领域的新手还是专家，好的决策都需要练习——而伟大的决策则建立在坚实的基础之上。Typekit Practice 是一个资源集合地，也是一个让你尝试新事物、磨练技能、保持敏锐的地方
- [justfreefonts](https://justfreefonts.com/)：免费软件、开源及公有领域字体合集——所有字体均可免费用于个人及商业用途
- [fontsource](https://fontsource.org/)：下载并自托管1500多种开源字体，这些字体已 neatly 打包为NPM包。免费获取全面的网页字体库
