### UI Design

#### Graphics & Components

- [sinwaver](https://www.sinwaver.com/): Generate perfect sine waves for your designs and backgrounds, and export them as SVG format.
- [heropatterns](https://heropatterns.com/): A collection of free, repeatable SVG background patterns for use in your digital projects.
- [transparenttextures](https://www.transparenttextures.com/): A collection of transparent texture background patterns.
- [patternico](https://patternico.com/): Create your own free seamless patterns and backgrounds online quickly and easily. Try our pattern generator – completely free!
- [fffuel](https://www.fffuel.co/): A fun collection of free SVG generators for gradients, patterns, shapes, textures, and cool backgrounds. Plus, some handy color tools for web designers.

#### Icons

#### Fonts

- [dafont](https://www.dafont.com/): Free fonts download archive. Browse by alphabetical order, style, author, or popularity.
- [fontsquirrel](https://www.fontsquirrel.com/): Font Squirrel scours the internet for high-quality, legally free fonts. Download thousands of completely legal, high-quality free fonts.
- [practice.typekit](https://practice.typekit.com/): Whether you're new to a field or an expert, good decisions take practice – and great decisions are built on a solid foundation. Typekit Practice is a collection of resources and a place to try new things, hone your skills, and stay sharp.
- [justfreefonts](https://justfreefonts.com/): A collection of freeware, open-source, and public domain fonts – all free for personal and commercial use.
- [fontsource](https://fontsource.org/): Download and self-host 1500+ open-source fonts neatly bundled as NPM packages. Access a comprehensive library of web typefaces for free.

### Public APIs

- [abstractapi](https://www.abstractapi.com/api/user-avatar-api): A free Avatar API that creates simple yet highly flexible user avatars using a user's name or initials. Add a splash of color and nice imagery to your interfaces.
